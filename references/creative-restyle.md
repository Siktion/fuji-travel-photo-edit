# 明确要求的创意重塑

本模式适用于用户明确要求的电影化、奇幻氛围或“魔界领域”风格处理。成片是创意编辑版本，不是原始天气和场景的事实记录。用户没有提出这类要求时，默认回到逐图规则中的纪实保真模式。

## 编辑合同

先列出：

- **保持不变**：照片里的主要地貌、道路、湖泊、建筑、车窗框架、人物身份/数量/姿势、构图与方向，以及用户指定的其他事实元素。
- **允许调整**：用户明确要求的色调、对比、雾气/云层氛围、局部纹理等。不要把“电影感”自行扩展为更换天气、增加闪电/太阳、替换天空、重画山体或新增人物。
- **禁止项**：假光源、过度 HDR、死黑天空/暗部、荧光颜色、强制青橙色、过度锐化、塑料皮肤、重复纹理、岩石/草地接缝、人物轮廓或建筑结构变形。

风格目标若可通过非生成式全局调色实现，优先走该路径；只有明确需要生成新氛围/修复内容且用户允许时才用生成式编辑。路人默认保留，只有用户指定对象和区域时才移除；复杂遮挡不能可靠恢复就保留痕迹。

每张分别以正确原图作为编辑目标，写出该图的真实主体和构图锚点；不可把上一张的寺庙、人像、草原等描述复制到不匹配的照片。横图/竖图分别确认输出方向。生成工具若改变了画幅、内容或输出尺寸，先拒收或标为需处理，不用其他照片补齐。

## 复核与标注

放大检查代表性的风景、人物和遮挡区域，至少检查山体轮廓、道路/建筑、湖岸、游客清理边缘和画面文字。生成式重绘会改变微细节；不得宣称像素级保真、打印级原尺寸母版或 RAW 显影。只有逐张看过的图才算人工审片；其余明确标为待复核候选。

如用户指定某个图像 API，按主技能的后端要求执行。实际后端不可用时停止该 API 任务，不把另一工具生成的图交付为 API 结果。
