# 人物面部保真与差异化方案

适用：旅行人像与合照。目的：修正光线和局部干扰，使人物精神、自然，同时保留身份、毛孔、皮肤细纹、年龄和表情。本文件是处理方案，不表示已应用到照片或已选择软件路线。

## 共同基线

1. 先校正曝光与白平衡，再判断是否真的需要处理皮肤。不把逆光暗部、偏色或 JPEG 噪声一概当作皮肤瑕疵。
2. 面部蒙版要避开眼睛、眉毛、嘴唇、头发和胡须；逐人建立，并与颈部、耳朵及手部色彩协调。边缘羽化，检查发际、耳缘和下巴，不能出现光圈或皮肤与背景色块断层。
3. 用轻微局部明暗均衡降低眼下阴影、鼻翼暗部和不均匀色斑的视觉干扰，保留原有骨骼与光线立体感。轮廓优化仅限现有光影，不改变脸型、颧骨、鼻梁、眼睛尺寸或下颌几何。
4. 点修仅针对已明确的临时痘痘、脱皮或小范围干扰；从相邻真实纹理取样，保留毛孔。痣、雀斑、疤痕或其他身份特征默认保留；单张图无法判断是否临时的斑点不自动删除。
5. 眼睛以原有可见细节为准，轻微局部清晰度即可。不得生成睫毛、放大眼睛、换瞳色或新增眼神光；眼白不刷成纯白。镜片反光如果遮住了眼睛，不能凭生成工具虚构眼睛并称恢复。
6. 鼻尖、额头反光可轻压，保留真实高光。暗部可适量降噪，但不能以模糊全脸换取干净。肤色调整不是漂白，不把高原自然红润完全去掉。

## 两种候选审美方向

如用户要求区分人物风格，可把下面作为候选方向；不能按性别自动套用。每个人可选择任一方向，实际强度按肤质、年龄与光线确定。

| 项目 | 女性候选：柔和通透 | 男性候选：自然立体 |
| --- | --- | --- |
| 曝光 | 使面部可读，温和过渡眼下、鼻翼阴影 | 使面部可读，同时保留现有鼻梁、颧骨与下颌明暗 |
| 肤色 | 减轻局部红/黄/灰偏色，保留自然红润及唇色 | 减轻红/紫偏色，保持本人真实肤色及面部与颈部协调 |
| 皮肤纹理 | 优先均匀肤色与明暗，只对明确干扰点修，保留毛孔与细纹 | 同样少量点修，保留毛孔、真实胡须及眉毛，不额外加粗或加深 |
| 眼周 | 温和减轻疲劳阴影，保留眼袋结构和笑纹 | 温和减轻疲劳阴影，保持眉眼细节；戴眼镜者核查镜片与眼睛 |
| 局部清晰度 | 皮肤避免明显锐化，现有眼睛与头发细节可轻微增强 | 眼睛、眉毛、胡须可选择性轻微增强，皮肤避免粗糙化 |
| 轮廓 | 现有光影柔和过渡，不瘦脸或缩鼻 | 保留现有轮廓光影，不雕刻新下颌线或人工加深阴影 |

长辈优先保留年龄特征，不把两种方向直接作为年轻化模板。合照中两人可以用不同局部强度，但整体白平衡与光源必须一致，不把两人肤色修成相同颜色。

## 常见场景的处理建议

- 逆光人物：平衡面部阴影与现场主光；只轻提脸部可读性并控制眩光偏色。背景单独保持原曝光关系，避免为了提亮脸部拉亮全片或改写日落天气。
- 双人近景：分别识别和调整两张脸，同时维持一致光源和整体白平衡。戴眼镜者保留镜片、眼睛与镜框关系；有胡须者保留原有毛发细节。任何人都不默认去痣、磨皮或漂白肤色。

## 强度与验收

默认轻修：曝光、肤色和少量局部明暗均衡；明显临时瑕疵按实际确认的目标点修。用户要求中度精修时仍不改变身份或全脸去纹理。不能把男性强度固定更高、女性亮度固定更白。

检查原始尺寸下的 100% 面部对照，以及整图缩放与手机观看效果。重点检查瞳孔、镜框、睫毛、痣、胡须、毛孔、皮肤过渡与颈部色差；不能为了在 400% 放大下无瑕而牺牲正常观看的真实性。

若工具不能局部选择或不能稳定保留原图细节，说明实际限制；提示词不是局部蒙版，也不能据其存在宣称只修改脸部。生成式输出只作明确标注的候选，背景或五官被重绘时拒绝采用。
